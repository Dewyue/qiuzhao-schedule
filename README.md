# 秋招日程

打开即用：https://dewyue.github.io/qiuzhao-schedule/

市面日历把**事件**当主角，空白只是底。秋招日程把**占用 vs 空闲**当主角：哪段被填满、哪段还能排、有没有撞车，同一套时间柱在「今天 / 接下来几天 / 本周」里一样清楚。

## 和普通日历不一样

- **空闲是可点的对象**，不是没画东西。点「空 1h20」就能预填开始时间。
- **一天一条时间柱**，实心=已占，浅轨=空着；重叠场次并排标出撞车。
- **今天、接下来几天、本周同一扫读方式**，只改列数，不换成三种完全不同的视图。
- **为秋招字段而生**：测评 / 笔试 / 面试（一面、二面）、时长按 10 分钟一档，而不是通用「会议」。
- **数据只在本机浏览器**，不登录、不上传；换设备用 JSON 导出/导入。

## 本地开发

```bash
npm install
npm run dev
```
